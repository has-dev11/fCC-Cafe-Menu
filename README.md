# ☕ Camper Cafe Menu

A responsive, visually styled menu web page for a fictional cafe, built as part of the [freeCodeCamp](https://www.freecodecamp.org/) Responsive Web Design curriculum.

---

## 🚀 Live Demo

- **Live Site URL:** [https://has-dev11.github.io/fCC-Cafe-Menu/](https://has-dev11.github.io/fCC-Cafe-Menu/)

---

## ✨ Features

- **Semantic Page Structure:** Built using clear HTML5 semantic elements to structure menu sections, item titles, prices, and footer details[cite: 1].
- **Responsive Layout:** Centered container design with customized spacing and typography that scales across screen sizes[cite: 1].
- **Custom CSS Styling:** Incorporates background images, custom font choices, color themes, and subtle visual dividers[cite: 1].
- **Menu Organization:** Structured itemization for Coffee and Dessert categories with aligned pricing[cite: 1].

## 🛠️ Built With

- **Semantic HTML5:** Clean structure and content hierarchy[cite: 1].
- **CSS3:** Box model, custom styling, background images, and layout alignment[cite: 1].
